# Descripción del Proyecto

Este trabajo práctico tiene como objetivo aplicar conceptos de gestión colaborativa, control de versiones y organización empresarial utilizando herramientas profesionales como Git, GitHub, Jira y Google Colab.

El proyecto desarrolla un análisis básico de ventas utilizando Python, permitiendo generar indicadores simples y gráficos a partir de datos simulados.

---

# Escenario Elegido

Escenario B – Análisis de Ventas de una Pequeña Empresa.
